Features

Built for Structured Document Collection

Build each project around the documents, people, permissions, and review steps it requires.

Public & Private Workflows

Invite specific collaborators to a private project or use a project code when participation should remain open.

Custom Document Requirements

Define document names, accepted file formats, size limits, and optional templates for collaborators to follow.

Assignment-Based Collection

For private projects, assign only the documents each collaborator is responsible for submitting.

Role-Based Project Access

Coordinate hosts, support staff, and collaborators with permissions suited to each person’s responsibilities.

Review & Revision Workflow

Approve or decline submissions, request revisions, and add comments so collaborators know what to address.

Progress & Organized Downloads

Follow submission progress by status and download approved documents together in an organized ZIP file.

Process

How It Works

Configure the workflow you need, review the price, activate the project, and manage every submission through completion.

1

Configure Your Project

Choose a public or private workflow, define document requirements and templates, add project members, and set the deadline.

2

Review Pricing & Pay

Review the usage-based project price, including the document assignments and project days, then complete secure checkout.

3

Activate & Invite

Activate the project, invite private collaborators or share a public project code, and give support staff access.

4

Collect, Review & Download

Track submissions by status, approve or decline documents, request revisions, and download approved files together.
